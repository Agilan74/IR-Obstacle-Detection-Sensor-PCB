# IR Obstacle Detection Sensor PCB

## Overview

This project is a custom IR Obstacle Detection Sensor PCB designed using KiCad.

## Features

- LM358 based design
- IR LED transmitter
- Photodiode receiver
- 100nF and 10uF filtering capacitors
- Compact PCB layout
